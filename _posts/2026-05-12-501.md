앱 개발 제안서 개요
1. Purpose (목적)
* 한글 개요: 영어 공부를 하면서 문맥에 따라 뜻이 달라지는 다의어 때문에 독해에 어려움을 겪은 경험이 있다. 이러한 어려움은 나뿐만 아니라 많은 학생들도 공감하는 문제이기 때문에, 이를 해결하기 위한 앱을 개발하고자 한다. 이 앱은 알고리즘을 활용해 문맥 속에서 단어의 정확한 의미를 분석하고, 사용자가 자주 틀리는 단어를 반복적으로 복습할 수 있도록 하여 학습 효율을 높이는 것을 목표로 한다.
* 필수 영단어:
    * 다의어: polysemy / words with multiple meanings
    * 구별하다, 식별하다: distinguish / identify
    * 문맥, 전후 사정: context
    * 향상시키다: enhance / improve
    * 학습 효율성: learning efficiency

2. Target Users Customers (타겟 사용자/고객)
* 한글 개요: 모의고사나 내신 영어 지문을 읽을 때 길고 복잡한 문장과 다의어 해석에 어려움을 겪는 중고등학생 및 수험생들
* 필수 영단어:
    * 중고등학생: middle and high school students
    * 수험생: test-takers
    * ~에 어려움을 겪다: struggle with / have difficulty in
    * 독해력: reading comprehension

3. Data Types & Data Usage (데이터 유형 & 데이터 활용)
* 한글 개요:
    * 데이터 유형: 수능 및 모의고사 기출 영어 텍스트 데이터, 사용자의 오답 및 학습 기록(수치 데이터).
    * 데이터 활용: 특정 다의어 주변에 어떤 단어들이 같이 쓰이는지(동시 등장 빈도)를 분석하여 문맥적 의미를 수학적으로 판별하는 머신러닝 알고리즘에 활용합니다. 또한 오답 데이터를 바탕으로 개인 맞춤형 복습 주기를 계산하는 데 사용합니다.
* 필수 영단어:
    * 텍스트 데이터: text data
    * 기출 지문: previous test passages
    * 사용자 오답 기록: user error logs
    * 분석하다: analyze
    * 수학적으로 계산하다: calculate mathematically

4. Key Features (핵심 기능 - 최소 2가지)
* 한글 개요:
    * Feature 1 (AI 문맥 분석기): 학생이 다의어가 포함된 헷갈리는 영어 문장을 입력하면, 주변 단어들을 알고리즘(Word2Vec 등)으로 분석하여 1, 2, 3번 뜻 중 가장 확률이 높은 정확한 뜻을 찾아줍니다.
    * Feature 2 (스마트 오답 복습 시스템): 사용자가 뜻을 잘못 맞혔던 다의어 문장들을 앱이 자동으로 저장합니다. 이후 '망각 곡선' 알고리즘에 기반하여, 잊어버릴 때쯤 다시 퀴즈 형식으로 알림을 보내 완벽히 외울 수 있게 돕습니다.
* Feature 3 (실생활 예문 매칭 시스템): 학습한 다의어의 특정 의미(예: 'run'이 '운영하다'로 쓰인 경우)가 실제 최신 영자 신문이나 TED 강연에서 어떻게 쓰이는지 알고리즘이 자동으로 검색하여 생생한 예문으로 제공해 줍니다.
    * 
* 필수 영단어:
    * 문맥 분석: context analysis
    * 확률: probability
    * 스마트 복습 시스템: smart review system
    * 망각 곡선: forgetting curve
    * 퀴즈 형식: quiz format

5. Potential Benefits (잠재적 이점)
* 한글 개요: 학생들은 단순히 단어장을 기계적으로 외우는 시간을 줄일 수 있습니다. 문맥을 논리적으로 파악하는 독해력을 기를 수 있고, 나만의 오답 복습을 통해 취약한 다의어를 단기 기억에서 장기 기억으로 확실하게 넘길 수 있습니다.
* 필수 영단어:
    * 논리적 독해: logical reading
    * 암기 시간을 줄이다: reduce memorization time
    * 장기 기억: long-term memory
    * 완벽히 익히다: master
